# ConsoleChat

ConsoleChat — это консольный чат на C# с поддержкой локального общения и сетевого режима через TCP.

## Возможности

### Пользователи
- Регистрация и вход
- Пароль с хешированием
- Переключение между профилями
- Online / Offline статус
- Фото профиля
- Просмотр фото других пользователей

### Чаты
- Личные чаты
- Групповые чаты
- Чат «Избранное»
- История сообщений
- Emoji
- Отправка файлов

### Сетевой режим
- TCP сервер
- Подключение клиентов по IP
- Общение на расстоянии
- Передача файлов по сети
- Несколько сетевых чатов
